# История изменений v1.0–v1.3

Описание составлено по **четырём загруженным исходным скриптам**, а не по ранее существовавшей истории Git. Все версии в `history/` **обезличены и адаптированы для публикации**; их нельзя считать побайтовыми копиями производственных сценариев.

## v1.3 — контролируемый запуск установщика

- `Start-Process -Wait -PassThru` заменён на `System.Diagnostics.ProcessStartInfo` / `System.Diagnostics.Process`.
- Добавлены запуск без оболочки и без окна, рабочий каталог, журналирование PID и проверка кода возврата.
- Добавлен тайм-аут **600 секунд** с попыткой завершения зависшего установщика.
- Из аргументов установки удалён `/ApplyConfig=...`: используется `/S /NoMaster`, после чего выполняется отдельный `veyon-cli config import`.
- При уже установленной **другой** версии скрипт всё ещё останавливается до установки — универсального автообновления нет.
- В оригинальном заголовке по ошибке оставалось `pilot v1.2`; исправлено только в публичной адаптации.

## v1.2 — проверка эффективной конфигурации

- Вместо отдельных `veyon-cli config get` выполняется экспорт конфигурации в JSON через `veyon-cli config export`.
- Это обходит выявленную проблему: `config get` для порта мог возвращать пустую строку, хотя эффективная конфигурация указывала TCP/11100.
- Временный JSON помещается в каталог с ограниченными ACL для SYSTEM и Administrators и удаляется по завершении.
- Проверяются ограничение доступа по группам, доменные группы, отключение автоматического исключения firewall, порт и **точный список** разрешённых групп операторов.
- Появились предупреждения о несоответствии эффективной конфигурации и ошибках экспорта.
- Отдельно загруженный файл `Install-Veyon.ps1` **полностью совпал по SHA256** с `Install-Veyon-v1.2.ps1`.

## v1.1 — нормализация firewall и восстановление

- Добавлена нормализация представления подсети `/255.255.255.0` в `/24` перед сравнением ограничений RemoteAddress.
- Добавлено обнаружение сохранённой после аварийного запуска временной блокировки TCP/11100 и проверка её параметров.
- Проверка `Already current` больше не завершается успехом при оставшейся временной блокировке.
- Исключено дублирование временного блокирующего правила при повторной попытке.

## v1.0 — первоначальная защищённая установка

- GPO / Scheduled Task под LOCAL SYSTEM; только клиентские Windows 10/11, без серверов и DC.
- Централизованный `manifest.json`, закреплённые SHA256, выбор архитектуры и повторная проверка локальных копий.
- Проверка Authenticode, именованный mutex, журнал операций.
- Контроль версии Veyon, состояния службы, конфигурации и ограничивающего firewall-правила для TCP/11100.
- Временное блокирующее правило при первой установке и запись контрольного состояния для последующих запусков.

## Ограничения исходных данных

Загруженные скрипты не подтверждают стопроцентный охват рабочих станций, отсутствие сбоев на всех клиентах, автоматический rollback или поддержку обновления с произвольных версий Veyon. Обезличенные файлы после подготовки публичной версии **не выполнялись на Windows**.
